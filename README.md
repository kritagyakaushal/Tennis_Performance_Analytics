# Tennis Performance Analytics

## Overview
This project uses Python to analyze tennis match statistics and create visualizations.

## Objectives
- Calculate first-serve percentages.
- Compare winners and double faults across matches.
- Present results using charts.

## Tools Used
- Python
- Pandas
- Matplotlib
- Google Colab

## Key Findings
The sample dataset showed that Match 4 had the highest first-serve percentage and the most winners, while Match 3 had the most double faults.

**Important:** These findings come from sample practice data, not actual match results.

## Skills Demonstrated
- Data organization
- Percentage calculations
- Data visualization
- Interpreting results

## Limitations
The dataset contains only four sample matches. It is not sufficient to establish reliable performance trends.
